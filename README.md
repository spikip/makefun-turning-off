## About this entry

The funniest tech support line is the one everyone has heard, delivered
by an agent who sounds delighted with himself. This entry opens with
the classic question, turning it off and on again, and then the agent
calls it step one of twelve, which reframes the most basic fix in the
world as the start of a long procedure. The punchline is the second
half: the agent has already forgotten step two, so the procedure is
dead on arrival and the customer is stuck with an expert who has no
plan. The humour comes entirely from the agent's cheerful uselessness,
never from the customer, which is exactly what the judge's brief asks
for. The line sounds like something a real support agent would say on
a bad day, and it stays well inside the one hundred and ninety nine
character cap. The program holds the line, checks it against that cap,
and writes it to /output/entry.txt exactly as the bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one-line joke to `/output/entry.txt`.
